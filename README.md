# نسخه 0.8.8: اصلاح خوش‌آمدگویی و خروجی T-SQL

- عنوان صفحه خوش‌آمدگویی در فارسی و انگلیسی کوتاه و تک‌سطر شده است؛ برای جلوگیری از بریدگی در ویندوز، حداقل ارتفاع عنوان و متن‌ها مشخص و کارت قابل اسکرول است.
- نام توسعه‌دهنده «علی صیادی» و مسئول آزمون «ماهان پاکروان‌نسب» در کارت حفظ شده‌اند.
- «Generate Scripts» حالا اسکریپت T-SQL مناسب اجرای مستقیم در **SQL Server 2012 تا 2025** برای **زیرمجموعه پشتیبانی‌شده** تولید می‌کند: `CREATE DATABASE`، `USE`، `CREATE TABLE`، `IDENTITY(seed,increment)`، کلید اصلی (تکی و ترکیبی)، `UNIQUE` (از جمله زوج FK جدول واسط)، ایندکس‌های ساده، `INSERT` با پشتیبانی Unicode، و `ALTER TABLE ... FOREIGN KEY`.
- `GO`، `SET ANSI_NULLS`، `SET QUOTED_IDENTIFIER` و `SET IDENTITY_INSERT` با ساختار قابل‌فهم برای SSMS صادر می‌شوند. ابتدا جدول‌ها ساخته می‌شوند، سپس داده‌ها درج می‌شوند و در آخر FKها با `WITH CHECK` ساخته و فعال می‌شوند.
- در حالت **فقط داده‌ها**، ترتیب درج براساس وابستگی والد/فرزند تعیین می‌شود. وابستگی چرخه‌ای در این حالت با خطای مشخص رد می‌شود.
- Schemaهای بدون تبدیل امن، مانند `CHECK` دلخواه SQLite یا نوع داده نامعتبر SQL Server، به‌جای حذف خاموش یا خروجی نادرست، با پیام خطای مشخص رد می‌شوند.
- فایل نمونه: [`examples/SQLServer_2022_TSQL_v0_8_8.sql`](examples/SQLServer_2022_TSQL_v0_8_8.sql). فایل را در یک نمونه **آزمایشی** SQL Server در SSMS باز و Execute کنید.

**محدودیت فنی مهم:** این خروجی فایل `.sql` است و **بکاپ باینری `.bak` نیست**. ماژول‌های View/Procedure/Function، کاربران، مجوزها، برخی تریگرها و ویژگی‌های خاص SQL Server هنوز در خروجی نیستند. موتور شبیه‌ساز SQLite است؛ اجرای واقعی در SQL Server، به‌ویژه نسخه‌های متفاوت مقصد، هنوز در این محیط آزمایش نشده است.

برای ساخت برنامه: در ویندوز `run_windows.bat` و پس از آزمایش، `build_windows.bat` را اجرا کنید. روی مک و لینوکس `bash run_unix.sh` قابل استفاده است.

## قابلیت‌های قبلی نسخه 0.8.6: ویرایش رکورد، واردکردن SQL و تکمیل خودکار

- **افزودن، ویرایش و حذف رکورد:** در تب Data یا پنجره Edit Rows، یک سطر را انتخاب کنید و از دکمه‌ها یا راست‌کلیک استفاده کنید. حذف دارای تأیید است و محدودیت‌های PK/FK اعمال می‌شوند.
- **اجرای فایل SQL:** از `File → Open SQL Script…` یا `Ctrl+Shift+O` فایل UTF-8 یا UTF-16 با پسوند `.sql` را انتخاب کنید. متن ابتدا برای بررسی در Query Editor نمایش داده می‌شود و اجرا نیاز به تأیید دارد. برخی دستورات T-SQL پشتیبانی نمی‌شوند و اسکریپت ممکن است پیش از بروز خطا بخشی از تغییرات را ثبت کرده باشد؛ ابتدا از دیتابیس بکاپ بگیرید.
- **تکمیل خودکار (IntelliSense آموزشی):** هنگام تایپ نام جدول، View، ستون یا کلیدواژه، فهرست پیشنهادها ظاهر می‌شود. `Ctrl+Space` فهرست را دستی باز می‌کند. با Enter یا Tab پیشنهاد را انتخاب کنید.
- **بزرگ‌نمایی Query Editor:** دکمه‌های `+`، `−` و `100%` بالای ویرایشگر، `Ctrl+Mouse Wheel` و کلیدهای `Ctrl++` / `Ctrl+=`، `Ctrl+-`، `Ctrl+0`.
- **بزرگ‌نمایی Diagram:** همین کلیدهای میانبر در تب نمودار فعال‌اند؛ دکمه‌های بزرگ‌نمایی نیز همچنان در نوار نمودار هستند.
- نمونه ورود: [`examples/SQL_Import_v0_8_4.sql`](examples/SQL_Import_v0_8_4.sql).

**محدودیت:** موتور برنامه SQLite است و تنها زیرمجموعه مستندشده T-SQL را اجرا می‌کند. `ALTER TABLE ... ADD FOREIGN KEY` تک‌ستونی به PK پشتیبانی شده است؛ اسکریپت‌های پیچیده واقعی SQL Server ممکن است به بازنویسی نیاز داشته باشند.


**طراحی و توسعه: علی صیادی**

ابزار دسکتاپ چندسکویی (ویندوز، مک و لینوکس) برای آموزش طراحی پایگاه داده، کلید اصلی و خارجی، جدول‌ها و نمودار روابط. این پروژه با **Python 3.12**، **PySide6 / Qt 6** و موتور ذخیره‌سازی **SQLite 3** ساخته شده است.

## پشتیبانی آزمایشی از T-SQL در نسخه 0.8.3

| دستور | رفتار در شبیه‌ساز |
|---|---|
| `CREATE DATABASE Name` | ساخت فایل محلی `Name.db` در پوشه پروژه |
| `USE Name` | انتخاب دیتابیس محلی موجود در همان پوشه |
| `GO` | جداکردن دسته‌دستورها در خط مستقل |
| `CREATE TABLE ... IDENTITY(seed,increment)` | ساخت جدول با یک زیرمجموعه ساده و کنترل‌شده از نحو SQL Server |
| `CREATE USER Name` | **فقط ثبت آموزشی در کاتالوگ شبیه‌ساز** |
| `GRANT` / `DENY` | **فقط ثبت نمایشیِ سطح دسترسی؛ بدون اعمال امنیت واقعی** |
| `DROP TABLE`, `ALTER TABLE ... DROP COLUMN` | حذف محافظت‌شده با بررسی وابستگی‌ها |

برای سایر دستورات SQL، موتور SQLite به کار می‌رود؛ لذا تمام امکانات SQL Server، از جمله `CREATE LOGIN`، نقش‌های امنیتی و فایل پشتیبان واقعی `.bak`، پیاده‌سازی نشده‌اند. دستور پشتیبانی‌نشده باید خطا بدهد، نه موفقیت ظاهری.

## پشتیبانی از ویندوز، مک و لینوکس در نسخه 0.8.3

سورس برنامه مشترک است؛ برای هر سیستم‌عامل یک بسته اجرایی جداگانه ساخته می‌شود.

| سیستم‌عامل | روش اجرای سورس | بسته خروجی |
|---|---|---|
| Windows | `run_windows.bat` | `.exe` و نصب‌کننده Inno Setup |
| macOS | `bash run_unix.sh` | برنامه `.app` در `.zip` و `.dmg` |
| Linux | `bash run_unix.sh` | `.tar.gz` و بسته `.deb` برای Debian/Ubuntu |

روی macOS و Linux برای ساخت بسته، به‌ترتیب `bash build_macos.sh` یا `bash build_linux.sh` را اجرا کنید.
همه بسته‌ها را می‌توان از بخش **Actions** مخزن و Workflow چندسکویی نیز ساخت؛ نیازی نیست کاربر سه سیستم‌عامل داشته باشد.

**وضعیت مهم:** سورس و اسکریپت‌های بسته‌بندی آماده‌اند، اما بسته‌های باینری macOS/Linux تا زمانی که GitHub Actions یا سیستم‌عامل مقصد Build را موفق انجام نداده‌اند، تأییدشده محسوب نمی‌شوند. این بسته‌ها امضا و Notarize نشده‌اند؛ برای انتشار عمومی مک باید امضای توسعه‌دهنده و Notarization اپل نیز بررسی شود.

## امکانات آموزشی View، Procedure و Function (نسخه 0.8.3)

- `CREATE VIEW`: ساخت **نمای واقعی SQLite** و خواندن آن با `SELECT`.
- `CREATE PROCEDURE` یا `CREATE PROC`: تعریف رویه ذخیره‌شده آموزشی با پارامتر ورودی و اجرای آن با `EXEC` یا `EXECUTE`؛ اجرای محدود `SELECT`، `INSERT`، `UPDATE`، `DELETE` و `SET NOCOUNT ON`.
- `CREATE FUNCTION`: ساخت **تابع اسکالر** با یک عبارت `RETURN` و فراخوانی از `SELECT`.
- نمایش Views، Stored Procedures و Scalar Functions در Object Explorer.
- استفاده از `GO` در خط مستقل پس از تعریف هر View، Procedure یا Function.
- مثال قابل اجرا: [`examples/TSQL_Modules_v0_8_3.sql`](examples/TSQL_Modules_v0_8_3.sql).

> توجه: این امکانات زیرمجموعه‌ای **آموزشی** از T-SQL هستند و جای موتور SQL Server را نمی‌گیرند. قابلیت‌هایی مانند Cursor، شرط و حلقه، TRY/CATCH، توابع جدول‌بر، پارامتر خروجی و SQL پویا پشتیبانی نشده‌اند. دستور ناسازگار خطا می‌دهد.
