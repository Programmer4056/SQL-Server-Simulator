# نسخه 0.8.8: اصلاح خوش‌آمدگویی و خروجی T-SQL

- عنوان صفحه خوش‌آمدگویی در فارسی و انگلیسی کوتاه و تک‌سطر شده است؛ برای جلوگیری از بریدگی در ویندوز، حداقل ارتفاع عنوان و متن‌ها مشخص و کارت قابل اسکرول است.
- نام توسعه‌دهنده «علی صیادی» و مسئول آزمون «ماهان پاکروان‌نسب» در کارت حفظ شده‌اند.
- «Generate Scripts» حالا اسکریپت T-SQL مناسب اجرای مستقیم در **SQL Server 2012 تا 2025** برای **زیرمجموعه پشتیبانی‌شده** تولید می‌کند: `CREATE DATABASE`، `USE`، `CREATE TABLE`، `IDENTITY(seed,increment)`، کلید اصلی (تکی و ترکیبی)، `UNIQUE` (از جمله زوج FK جدول واسط)، ایندکس‌های ساده، `INSERT` با پشتیبانی Unicode، و `ALTER TABLE ... FOREIGN KEY`.
- `GO`، `SET ANSI_NULLS`، `SET QUOTED_IDENTIFIER` و `SET IDENTITY_INSERT` با ساختار قابل‌فهم برای SSMS صادر می‌شوند. ابتدا جدول‌ها ساخته می‌شوند، سپس داده‌ها درج می‌شوند و در آخر FKها با `WITH CHECK` ساخته و فعال می‌شوند.
- در حالت **فقط داده‌ها**، ترتیب درج براساس وابستگی والد/فرزند تعیین می‌شود. وابستگی چرخه‌ای در این حالت با خطای مشخص رد می‌شود.
- Schemaهای بدون تبدیل امن، مانند `CHECK` دلخواه SQLite یا نوع داده نامعتبر SQL Server، به‌جای حذف خاموش یا خروجی نادرست، با پیام خطای مشخص رد می‌شوند.
- فایل نمونه: [`examples/SQLServer_2022_TSQL_v0_8_8.sql`](examples/SQLServer_2022_TSQL_v0_8_8.sql). فایل را در یک نمونه **آزمایشی** SQL Server در SSMS باز و Execute کنید.

**محدودیت فنی مهم:** این خروجی فایل `.sql` است و **بکاپ باینری `.bak` نیست**. ماژول‌های View/Procedure/Function، کاربران، مجوزها، برخی تریگرها و ویژگی‌های خاص SQL Server هنوز در خروجی نیستند. موتور شبیه‌ساز SQLite است؛ اجرای واقعی در SQL Server، به‌ویژه نسخه‌های متفاوت مقصد، هنوز در این محیط آزمایش نشده است.

برای ساخت برنامه: در ویندوز `run_windows.bat` و پس از آزمایش، `build_windows.bat` را اجرا کنید. روی مک و لینوکس `bash run_unix.sh` قابل استفاده است.

## رفع ایرادات گزارش‌شده

۱. **عدم وجود جدول:** برنامه قبل از بازکردن جدول، فهرست واقعی `sqlite_master` را بررسی می‌کند. در صورت تغییر ساختار دیتابیس، Object Explorer و نماها به‌روز می‌شوند و تب‌هایی که به جدول حذف‌شده اشاره دارند بسته می‌شوند.

۲. **تم تاریک:** آیکن‌های نوار ابزار و پالت Qt با تم هماهنگ شده‌اند.

۳. **اندازه پنجره:** حداقل اندازه پنجره کاهش یافته است؛ Object Explorer، Properties و Query Results امکان تغییر اندازه، شناور شدن و بستن دارند. از **View → Reset Window Layout** برای بازیابی استفاده کنید.

۴. **نمودار:** از **Auto Layout** برای چیدمان خودکار استفاده کنید. با **Ctrl + چرخ ماوس** بزرگ‌نمایی و با **کشیدن دکمه وسط ماوس** روی بوم حرکت کنید.

۵. **حذف:** روی کارت جدول در نمودار یا نام جدول در Object Explorer راست‌کلیک کنید؛ گزینه‌های **Drop Column** و **Drop Table** وجود دارند. حذف باید تأیید شود و در صورت وابستگی کلید خارجی، برنامه از حذف ناامن جلوگیری می‌کند.

## دستورات SQL Server

از داخل Query Editor امکان اجرای زیرمجموعه‌ای از دستورات `CREATE DATABASE`، `USE` و `GO` وجود دارد. نمونه آماده در مسیر `examples/TSQL_Teaching_v0_7.sql` قرار دارد. ساخت جدول با نحو ساده `CREATE TABLE` و `IDENTITY(seed, increment)` پشتیبانی می‌شود.

**تذکر بسیار مهم:** `CREATE USER`، `GRANT` و `DENY` فقط اطلاعات آموزشی در جداول مخفی شبیه‌ساز ثبت می‌کنند. این دستورات در موتور SQLite دسترسی کاربران را کنترل نمی‌کنند و نباید برای مدیریت امنیت واقعی استفاده شوند. دیگر دستورات اختصاصی SQL Server ممکن است پشتیبانی نشوند و خطا بدهند.

## امکانات آموزشی View، Procedure و Function (نسخه 0.8.3)

- `CREATE VIEW`: ساخت **نمای واقعی SQLite** و خواندن آن با `SELECT`.
- `CREATE PROCEDURE` یا `CREATE PROC`: تعریف رویه ذخیره‌شده آموزشی با پارامتر ورودی و اجرای آن با `EXEC` یا `EXECUTE`؛ اجرای محدود `SELECT`، `INSERT`، `UPDATE`، `DELETE` و `SET NOCOUNT ON`.
- `CREATE FUNCTION`: ساخت **تابع اسکالر** با یک عبارت `RETURN` و فراخوانی از `SELECT`.
- نمایش Views، Stored Procedures و Scalar Functions در Object Explorer.
- استفاده از `GO` در خط مستقل پس از تعریف هر View، Procedure یا Function.
- مثال قابل اجرا: [`examples/TSQL_Modules_v0_8_3.sql`](examples/TSQL_Modules_v0_8_3.sql).

> توجه: این امکانات زیرمجموعه‌ای **آموزشی** از T-SQL هستند و جای موتور SQL Server را نمی‌گیرند. قابلیت‌هایی مانند Cursor، شرط و حلقه، TRY/CATCH، توابع جدول‌بر، پارامتر خروجی و SQL پویا پشتیبانی نشده‌اند. دستور ناسازگار خطا می‌دهد.

## امکانات نسخه 0.8.5 (حفظ‌شده در 0.8.7)

- **رابطه چندبه‌چند (N:M):** ایجاد خودکار جدول واسط با دو کلید خارجی واقعی. انتخاب کلید اصلی ترکیبی از FKها، یا کلید اصلی مستقل `IDENTITY` همراه با قید `UNIQUE` برای ترکیب FKها.
- **رابطه یک‌به‌چند (1:N):** در Relationship Wizard می‌توان کلید اصلی مستقل فرزند را حفظ کرد یا کلید خارجی را به کلید اصلی ترکیبی فرزند اضافه کرد. حالت دوم برای جدولی که `IDENTITY` در کلید اصلی دارد پشتیبانی نمی‌شود.
- **Generate Scripts:** پس از انتخاب جداول، محتوا و نسخه مقصد SQL Server، خروجی را به‌صورت فایل `.sql` در مسیر دلخواه ذخیره کنید یا بدون اجرا در SQL Query Editor باز کنید.
- **ویرایش مستقیم رکوردها:** در نمای جدول روی سلول دوبار کلیک کنید یا کلید `F2` را بزنید. مقدار جدید همان‌جا و با کنترل‌های دیتابیس ثبت می‌شود؛ شناسه‌های `IDENTITY` قابل ویرایش نیستند. برای NULL عبارت `NULL` و برای ذخیره متن واقعی «NULL» عبارت `\\NULL` وارد کنید.
- **صفحه خوش‌آمدگویی:** کارت مرکزی جمع‌وجور با قابلیت پیمایش در پنجره‌های کوچک.
- **گزارش خطا:** عنوان و متن اولیه ایمیل Gmail و mailto بر اساس زبان فارسی یا انگلیسی تنظیم می‌شوند.
- **زوم:** میانبرهای `Ctrl++`، `Ctrl+=`، `Ctrl+-` و `Ctrl+0`، دکمه‌های + و −، و `Ctrl+Scroll` در ویرایشگر SQL و نمودار.
- **زبان:** برچسب‌های بیشتری در فرم‌ها و پنجره‌های تأیید ترجمه شده‌اند. پیام‌های خطای رایج به فارسی توضیح داده می‌شوند و متن فنی اصلی در بخش جزئیات قابل مشاهده است.

**محدودیت‌ها:** شبیه‌ساز همچنان از SQLite استفاده می‌کند و تمام T-SQL واقعی را اجرا نمی‌کند. برخی پیغام‌های کمتر رایج یا متن تشخیصی ابزارهای سیستمی ممکن است انگلیسی بمانند. تغییرات گرافیکی روی سیستم‌عامل مقصد نیازمند تست تعاملی هستند.

## امکانات تکمیلی نسخه 0.8.7 (نامزد انتشار)

- **اعتبارسنجی قبل از درج و ویرایش:** کنترل مقدار کلید خارجی در جدول والد، اجباری بودن فیلدها، نوع عددی/متنی/تاریخ، دامنه BIT و طول NVARCHAR. محدودیت‌های واقعی SQLite هم همچنان فعال هستند.
- **افزودن پشت سر هم رکوردها:** در صفحه نمایش داده‌ها، ردیف آخر با عنوان «جدید» برای ورود مستقیم قرار دارد. با Tab بین ستون‌ها حرکت کنید، «ذخیره ردیف جدید» را بزنید و در ردیف جدید بعدی ادامه دهید. گزینه فرم جداگانه همچنان برای کاربرانی که آن را ترجیح می‌دهند موجود است.
- **ویرایش مستقیم:** سلول‌های غیر Identity در خود جدول قابل ویرایش‌اند و مقدار نامعتبر ذخیره نمی‌شود. برای ذخیره ردیف جدید می‌توانید از Ctrl+Enter نیز استفاده کنید.
- **مسئول آزمون و ارزیابی نرم‌افزار:** ماهان پاکروان‌نسب. این نام در صفحه خوش‌آمدگویی و بخش درباره نرم‌افزار درج شده است.

**توجه:** این نسخه نامزد انتشار است. تست‌های منطق دیتابیس در محیط فعلی اجرا می‌شوند؛ تست‌های گرافیکی PySide6 و نصب روی سیستم‌عامل‌های مقصد باید پیش از انتشار عمومی تأیید شوند.
