# v0.3.0 updates

- Qt table designer: SQL Server-oriented type dropdown, parameter dialog for string length and decimal precision.
- Identity Specification: seed and increment controls, generated by SQLite triggers, persisted as project metadata; tests cover custom sequences.
- Diagram tab: prominent Connect Tables button, plus relationship wizard and FK constraints.
- Data entry: grid-style Edit Rows dialog, explicit NULL behavior, identity read-only.
- Safer table rebuild: populated child rows can be preserved when new FK constraints are satisfied; reject orphaning/incoming populated dependencies.
- Generate Scripts Wizard: choose tables, schema/data/both, target SQL Server version, Unicode values, primary/foreign keys and identity with `IDENTITY_INSERT` for existing data.
- All source and tests, Windows EXE and Inno Setup builders included; binaries must be built on Windows.
